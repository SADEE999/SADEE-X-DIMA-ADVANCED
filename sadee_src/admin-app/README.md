# SADEE X DIMA ADMIN APP

Standalone Android wrapper for the separate SADEE X DIMA Gaming Admin Panel.

The login/security gate has intentionally been removed as requested. The app opens the admin dashboard directly.

The web admin still needs the Supabase URL + publishable/anon key in `admin-panel/admin.js` for live database operations. Never place a Supabase service-role key in this app.
